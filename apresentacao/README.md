# Caminho dos Direitos

Projeto desenvolvido para a Global Solution da FIAP. O Caminho dos Direitos propõe aproximar famílias em situação de vulnerabilidade de documentos, benefícios sociais e serviços públicos em São Paulo.

## Apresentações

- [Apresentação Completa](apresentacao/GS_2TSCPV_Pitch_Caminho_dos_Direitos_AgentesTech.pdf) — reúne a pesquisa de campo, os protótipos, a arquitetura de dados e os links dos entregáveis.
- [Pitch — apresentação resumida](https://youtu.be/J50OedLo1p4) — apresenta o problema, a solução e os impactos esperados.

## Como a solução funciona

- **App para agentes comunitários de saúde e assistentes sociais** — apoia a orientação às famílias, o registro de encaminhamentos e o envio de lembretes por WhatsApp.
- **Painel de acompanhamento** — permite acompanhar o andamento dos encaminhamentos e visualizar as principais pendências por território.
- **Modelo de priorização territorial** — ajuda a gestão pública a identificar onde concentrar ações, como mutirões de documentação.

A proposta foi construída a partir de uma pesquisa de campo com agentes comunitários de saúde e moradores do Jardim Ângela e de Paraisópolis.
